# HVAC-Duct-Design — памятка для Claude (читайте первой)

Владелец — **начинающий программист**: пишет на C# и IronPython 3 под pyRevit, **говорит и читает по-русски**. Отвечайте по-русски,
просто, без лишнего жаргона; код комментируйте по-русски, в стиле соседнего кода. Не ссылайтесь на себя как на конкретную модель
в коммитах, PR и коде.

## Два плагина (суть)
- **QuickFlexConnect** — гибкий воздуховод между двумя элементами за два клика (по ближайшим к клику свободным коннекторам;
  окно размера и типа; круглые/прямоугольные/овальные; настройки «Тип с образца», «Цикл», параметр «Гибкая конфигурация»).
- **FlexTail** — клик по оборудованию/арматуре/фасонной детали/воздухораспределителю → часть подключённого жёсткого
  воздуховода заданной длины (по умолчанию 500 мм) заменяется гибким; длиннее воздуховода — подставляется максимум.
Подробности — `pyrevit/README.md` (поведение) и `docs/CSHARP-PORT.md` (что переносить).

## Правила работы
1. **Ветка и PR.** Разработка — в ветке, назначенной сессией; после push — черновой PR. Слияние в `main` делает только по явной
   команде владельца («слей»).
2. **Язык интерфейса — русский** (кроме SystemsTemplate — он украинский). Тексты окон должны совпадать со слайдами.
3. **Единый стиль окон** (см. `pyrevit/HVAC.extension/lib/hvac_ui.py`): тёмно-синяя шапка `#14213D`, светлый фон `#FBFAF6`,
   акцент янтарный `#F2A93B`, голубой `#5BB6E8`, шрифт Segoe UI в окнах, IBM Plex Sans на слайдах. Окна без системной рамки,
   перетаскиваются; поля ввода принимают только число; в каждом поле кнопка «×».
4. **Каждая кнопка — свои журнал и настройки** в папке кнопки (`<кнопка>.log`, `settings.ini`); окна вывода pyRevit не используем.
5. **Проверка.** Любое изменение pyRevit-кода — с тестами; перед коммитом прогнать весь набор. Что нельзя проверить без
   живого Revit, честно помечайте как «не проверено в Revit».
6. **Слайды обновляйте вместе с кодом** (окна, тексты, поведение) и пересобирайте PDF — инструкция в `slides/README.md`.
7. Большие артефакты (архив, PDF) лежат в `dist/`; ссылки владельцу давайте прямые (`.../raw/<ветка>/dist/...`).
