Тип можно взять с образца в модели

QuickFlexConnect · 3/3 — укажите образец: клик по гибкому воздуховоду, тип возьмётся с него (Esc — выбрать из списка)

Когда запрашивается

Размеры коннекторов одинаковые и включена настройка «Тип с образца».

Что сделать

Кликнуть по гибкому воздуховоду в модели. Кликать можно только по гибким воздуховодам; тип берётся с него.

Если не подошло

Esc — переход к списку типов. Если тип не подходит по форме, будет предупреждение и тот же список.
