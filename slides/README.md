# Слайды: как устроены и как их корректировать

Две презентации на русском, в одном стиле, **не привязаны к pyRevit** (рассказывают про плагин, а не про технологию):

| Презентация | Исходники | PDF | Онлайн-версия (Artifact, приватная — открывается у владельца) |
|---|---|---|---|
| QuickFlexConnect (13 слайдов) | `slides/QuickFlexConnect/` | `dist/QuickFlexConnect-slides.pdf` | https://claude.ai/artifact/9MDMti2rr7vgm315CHnRve |
| FlexTail (10 слайдов) | `slides/FlexTail/` | `dist/FlexTail-slides.pdf` | https://claude.ai/artifact/3zZtEC2EKZWuuB18vAWBfp |

Исходники в репозитории — **главные**: правим их, потом публикуем в онлайн-версию и пересобираем PDF.

## Устройство
```
slides/<Презентация>/project/deck.json        порядок слайдов (order), разделы (sections), шрифт
slides/<Презентация>/project/slides/<id>.html один слайд = один <section> с инлайн-стилями, холст 1920×1080
```
Слайд — обычный HTML, все стили **внутри атрибутов `style`**. В теге `<aside>` внутри слайда — заметки докладчика.
Артефактные теги: `<x-shape kind="arrow-down">` (стрелка списка) и `<x-icon name="Check">` (галочка) — в PDF заменяются
скриптом на обычную разметку; новых `<x-…>` тегов не добавляйте. Номер слайда в правом нижнем углу (`text-align:right">NN`) —
**пишется вручную**: вставили/убрали слайд — перенумеруйте остальные (и поправьте `order` в `deck.json`).

## Стиль (не нарушать)
- Цвета: тёмный фон `#0E1A2B`, карточки на тёмном `#16263D` (рамка `#2A3E5C`), светлый фон `#F3F0E8`, карточки `#FBFAF6`
  (рамка `#DDD8CB`), текст `#14213D` / `#3A4660` / приглушённый `#5B6677`; акцент `#F2A93B`, синий `#5BB6E8`, зелёный `#5FCF9A`,
  ошибка `#B03A3A` (на тёмном — светлее `#E5706E`). Шрифт IBM Plex Sans (400/600/700).
- Размеры: заголовок слайда 72 px (одна строка, ≤ ~40 символов, **заголовок — вывод, а не название темы**), подписи ≥ 24 px,
  минимум в нарисованных окнах 20 px; отступ слайда `128px 128px 160px`; колонтитул внизу слева («Название · Revit 2026»).
- Окна на слайдах **нарисованы вручную из HTML и должны совпадать с настоящими окнами плагина** (тексты, порядок полей,
  кнопки) — владельцу нравится их похожесть на настоящие. Меняете окно в коде — меняйте и слайд.
- Один слайд — одна мысль; у слайдов с окном: окно слева, справа 2–4 карточки-пояснения с янтарными номерами.

## Проверка и PDF (нужны node + playwright + Chromium; в облачной сессии они есть)
```bash
W=$(mktemp -d); python3 tools/slides/build_print.py slides/FlexTail "$W"; cp tools/slides/*.js "$W"; cd "$W"
NODE_PATH=$(npm root -g) node audit.js         # «no issues» или список: CONTRAST / SMALL / OUT / LOW / CLIP
NODE_PATH=$(npm root -g) node render.js ft     # ft.pdf и ft-01.png … (скриншоты слайдов — посмотрите их глазами!)
cp ft.pdf <репозиторий>/dist/FlexTail-slides.pdf
```
(для QuickFlexConnect то же с `slides/QuickFlexConnect` и `render.js qfc`). Аудит ловит наезд текста на колонтитул (`LOW`:
контент ниже 975 px) и низкий контраст; **скриншоты всё равно смотрите** — аудит не видит наложение рисунков.

## Публикация в онлайн-версию (Artifact)
Онлайн-версии — артефакты типа «Slides»; публикуются инструментом `Artifact` (не `git`):
1. `Artifact` с `url` артефакта, `root` = `…/slides/<Презентация>`, `file_path` = `…/project/slides/<изменённый>.html`,
   `files` = остальные изменённые файлы (`["project/slides/x.html", "project/deck.json"]`). Файлы, которых нет в списке, остаются.
2. Если инструмент отказывает («файлы опубликованы, но вы их не читали») — прочитайте их `Artifact action=read url=… path=…`,
   убедитесь, что это ваши прежние версии, и повторите публикацию.
3. Артефакты приватные; читать/править их может только владелец-аккаунт, поэтому новой сессии нужен тот же аккаунт.
Если артефакт недоступен — создайте новый тем же способом (`Artifact action=quickstart intent=slides`, затем публикация файлов
из `slides/…`) и обновите ссылки в этом файле.
