# HVAC Duct Design — палитра систем вентиляции

Статическая страница-лендинг в стиле чертежа Revit: воздуховоды в плане, цветовое кодирование
приточных (П1–П40) и вытяжных (В1–В40) систем.

## Запуск

Сборки нет — откройте `index.html` в браузере. Или локально: `python3 -m http.server` и http://localhost:8000.

## Как устроена палитра

- Боковые стенки воздуховода: приточные — красный `255,0,0`, вытяжные — синий `0,0,255`.
- Заливка внутри — цвет системы. На группу 10 базовых оттенков (`js/palette.js`, объект `BASE`),
  порядок подобран так, чтобы соседние номера сильно отличались.
- Системы 11–40 повторяют оттенки 1–10, но с другой заливкой (в Revit — образец штриховки в фильтре вида):
  11–20 диагональная штриховка, 21–30 сетка, 31–40 точки. Например, П11 = П1 + штриховка.
- Проверка: для любых 10 систем подряд считается ΔE (CIEDE2000). Пары с разной заливкой считаются
  различимыми. Результат показан на странице; ΔE ≥ 15 — уверенно разные цвета, ≥ 20 — кардинально.

## Как поменять цвет

Правьте `hex` в `BASE.supply` / `BASE.exhaust` в `js/palette.js`. Таблица проверки на странице пересчитается сама.
Из Node то же самое можно проверить: `node -e "const P=require('./js/palette.js'); console.log(P.windowStats(P.SYSTEMS.supply,10))"`.

## Экспорт

Кнопки CSV и JSON в ленте сверху выгружают все 80 систем (RGB, HEX, тип заливки, цвет стенок).
