# QuickFlexConnect — краткое техническое задание

**Платформа:** Revit 2026, pyRevit (IronPython 3). **Назначение:** построить гибкий воздуховод между двумя коннекторами двумя кликами.

**Название:** кнопка и команда — `QuickFlexConnect` (папка `101_QuickFlexConnect.pushbutton` на вкладке HVAC, панель Systems).

## 1. Цель

Заменить ручную прокладку гибкого воздуховода между двумя элементами (выбор типа, рисование кривой, привязка концов к коннекторам, подбор размера, заполнение параметра) одной кнопкой: клик по первому элементу, клик по второму, Enter.

Вне рамок: трубопроводы, кабельные лотки, автотрассировка, переходы, перебор вариантов трассы.

## 2. Какие элементы можно соединять

Клик по элементу: берётся свободный коннектор, **ближайший к месту клика** (у воздуховода — тот конец, у арматуры с несколькими врезками — та врезка). Допустимы только категории из списка `ALLOWED_CATEGORIES`:

| Категория | BuiltInCategory | По умолчанию |
|---|---|---|
| Воздуховоды | `OST_DuctCurves` | разрешено |
| Арматура воздуховодов | `OST_DuctAccessory` | разрешено |
| Соединительные детали воздуховодов | `OST_DuctFitting` | разрешено |
| Оборудование | `OST_MechanicalEquipment` | разрешено |
| Воздухораспределители | `OST_DuctTerminal` | разрешено |

Условие допуска: у элемента есть коннекторы домена HVAC. Реализация — `ISelectionFilter`; если все коннекторы уже подключены, плагин объясняет это и пишет детали в журнал, а элементы без вентиляционных коннекторов не выбираются (причина — в журнале). Гибкие воздуховоды, трубы и прочее выбирать нельзя. Один и тот же элемент дважды выбрать нельзя.

## 3. Функциональные требования

1. **Пара коннекторов.** Для каждого элемента берётся свободный коннектор, ближайший к точке клика (выбор целого элемента `ObjectType.Element`, точка — `Reference.GlobalPoint`; точка на элементе при выборе не показывается). Если точки клика нет — пара с минимальным расстоянием между свободными коннекторами. Подсказки шага («1/2», «2/2», что уже выбрано, Esc) выводятся в строку состояния Revit (текст запроса `PickObject`).
2. **Сечение и размер.** По `Connector.Shape`: круглое (диаметр), прямоугольное и овальное (ширина × высота). Размеры считаются равными, если форма одна и разница не больше 0,5 мм.
3. **Построение.** `FlexDuct.Create` по двум точкам и касательным вдоль `BasisZ` коннекторов (Revit 2025+); запасной вариант — четыре точки. Система — из коннектора (`MEPSystem`), иначе запрос типа системы. Уровень — элемента 1, иначе уровень вида, иначе ближайший по высоте. Размер: диаметр или ширина и высота. Затем `ConnectTo` для обоих концов.
4. **Параметр «Гибкая конфигурация»** (`BuiltInParameter.RBS_FLEX_PATTERN_PARAM`). Значение из настроек записывается после построения: сначала в экземпляр, если параметра нет — в тип. Значение выбирается из списка вариантов проекта (читаются перебором в откатываемой транзакции); по умолчанию «Гибкий»; пункт «не менять» отключает запись. Число варианта запоминается, чтобы не перебирать его при каждом запуске.
5. **Транзакция.** Одна на пару; ошибка — откат. Кривые короче 1/10 дюйма не строятся — плагин сообщает об этом.

## 4. Настройки

Окно по Shift+клик на кнопке. Хранение — конфигурация pyRevit, секция `flex_between`. Если окно не создаётся, используются стандартные диалоги pyRevit.

| Настройка | Значения | По умолчанию | Поведение |
|---|---|---|---|
| «Гибкая конфигурация» | вариант из списка проекта или «не менять» | «Гибкий» | запись параметра после построения |
| Тип с образца в модели | вкл / выкл | выкл | клик по гибкому воздуховоду вместо списка типов |
| Цикл | вкл / выкл | выкл | пары подряд до Esc |

## 5. Сценарии

**Выбор типа.** Режим «Список» (по умолчанию): компактное окно с одним выпадающим списком, последний выбранный тип подставлен, Enter подтверждает, Esc отменяет; если тип один — окна нет. Режим «Образец в модели»: запрос «клик по гибкому воздуховоду» (фильтр — только гибкие воздуховоды), тип берётся с образца; Esc — переход к списку; тип не подходит по форме — предупреждение и список. Список типов фильтруется по форме (`Shape` типа), если Revit её отдаёт.

**Сценарий А — без окна.** Размеры равны + включена опция «Тип с образца»: три клика (элемент 1, элемент 2, образец), построение без окон. Так же без окна, если тип в проекте один.

**Сценарий Б — с окном.** Размеры или форма разные: окно открывается сразу после выбора пары, даже при включённой опции «Тип с образца». В окне два чипа с размерами элементов 1 и 2 (по умолчанию выбран первый, Enter подтверждает), список «Другой размер…» со стандартными круглыми диаметрами проекта (`DuctSizeSettings`), для прямоугольных и овальных сечений — два списка «Ширина…» и «Высота…» со стандартными размерами проекта (оставшийся невыбранным размер берётся с плашки) и список типа, подстраивающийся под форму выбранного размера. Esc или закрытие окна — отмена без построения.

**Цикл.** Включён — после построения плагин сразу просит следующую пару; тип запоминается на серию и не спрашивается, пока подходит по форме. Выключен — одна пара за запуск.

## 6. Нефункциональные требования

- **Скорость:** при успехе не открывать окно вывода pyRevit; результат фильтра выбора кешировать по элементу, тип элемента определять по классу Revit без исключений; значение «Гибкая конфигурация» писать без перерасчёта модели (число варианта привязано к версии и языку Revit, результат проверяется после транзакции); тяжёлые модули (`pyrevit.forms`, `uuid`, `tempfile`, `traceback`) грузить только при необходимости; журнал писать одним открытием файла и фиксировать тайминги запуска.
- **Журнал:** файл `%APPDATA%\HVAC-Duct-Design\hvac-tools.log` — движок и версия Revit, шаги работы, полный traceback ошибок, ротация при 512 КБ. При ошибке — диалог с путём к журналу и traceback в окне вывода. Esc ошибкой не считается.
- **Совместимость:** IronPython 3.4 (без f-строк); установка — папка `HVAC.extension` целиком вместе с `lib`.
- **Тесты:** автотесты на заглушках API Revit (запуск: `python3 -m unittest discover -s pyrevit/tests`).

## 7. Критерии приёмки (в живом Revit 2026)

1. Элементы одного размера соединяются без окна при включённой опции «Тип с образца».
2. Разные размеры — окно сразу; чипы дают оба размера; «Другой размер…» даёт стандартные диаметры, а для прямоугольных и овальных сечений «Ширина…» и «Высота…» дают стандартные размеры проекта.
3. Круглое, прямоугольное и овальное сечения получают верный размер; концы воздуховода соединены с коннекторами.
4. Элементы других категорий выбрать нельзя.
5. «Гибкая конфигурация» записывается; по умолчанию — «Гибкий».
6. «Цикл» строит пары подряд до Esc; выключен — одна пара.
7. Любая ошибка оставляет traceback в журнале.

## 8. Допущения, которые нужно проверить в Revit

- Форма типа гибкого воздуховода доступна как `Shape` (иначе список типов не фильтруется).
- Стандартные диаметры, а также ширины и высоты прямоугольных и овальных размеров читаются из `DuctSizeSettings` (поля `NominalWidth` / `NominalHeight` записей списка; иначе списки неактивны или отсутствуют).
- `RBS_FLEX_PATTERN_PARAM` — параметр-список (целое число с текстом); варианты читаются перебором значений.
